name: refactor-js
description: How to refactor JS code with best practices
---
- Check `AGENTIC_CHANGES.md` to see if the file has already been refactored. If the file doesn't exist, add it to the root of the project.
- If the file has already been refactored, stop.
- Follow test-driven development principles.
- Read the existing code and understand its purpose and functionality in detail.
- Write unit tests for the existing code, run them and make sure they pass.
- Identify areas of the code that need to be refactored.
- If you find a rule that isn't part of the rules mentioned to you, add it to the appropriate rules file.
- Refactor the code to improve its structure and readability according to the standards I provided to you.
- Run the unit tests again to make sure the code still works.
- Document the changes you made in `AGENTIC_CHANGES.md`.
